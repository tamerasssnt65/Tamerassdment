# Tamer — منصة تقييمات أولى ثانوي الاحترافية

## الفكرة
البرنامج يفحص مصادر وزارة التربية والتعليم دوريًا، يكتشف ملفات التقييمات الجديدة، يحاول تنزيلها، يقرأ PDF/DOCX، ثم يرسل الملف للنموذج عبر OpenAI Responses API للحصول على حل منظم، ويحفظ الحل في قاعدة البيانات.

## المواد
مهيأ للتعرف على: العربي، الإنجليزي، الرياضيات، العلوم المتكاملة، التاريخ، الفلسفة والمنطق، البرمجة والذكاء الاصطناعي، والتربية الدينية.

## التشغيل
```bash
python -m venv .venv
# فعّل البيئة
pip install -r requirements.txt
# انسخ .env.example إلى .env واضبط OPENAI_API_KEY
python app.py
```
ثم افتح `http://localhost:8000`.

## النشر 24/7
شغّل:
```bash
gunicorn --bind 0.0.0.0:$PORT --workers 1 --timeout 180 app:app
```
ويجب وضع `OPENAI_API_KEY` كـ Secret/Environment Variable في الاستضافة.

## دورة العمل
1. فحص المصادر كل 20 دقيقة افتراضيًا.
2. اكتشاف الروابط الجديدة وحفظها ببصمة URL.
3. تنزيل PDF/DOCX/صورة عند توفره.
4. استخراج النص كمسار احتياطي.
5. إرسال الملف للنموذج عندما تسمح الواجهة بذلك.
6. حفظ الحل وعرضه في صفحة التقييم.
7. لو فشل عنصر، يتحول إلى `error` ويمكن إعادة حله يدويًا.

## ملاحظات مهمة
- الوزارة قد ترجع HTTP 403 أو تغير بنية الموقع، لذلك لا يمكن ضمان الاكتشاف من غير تشغيل خادم خارجي قادر على الوصول للمصدر.
- لا توجد إجابة "رسمية" من الوزارة؛ الحلول هنا مولدة آليًا ويجب مراجعتها.
- لا تضع مفتاح API في JavaScript أو HTML.
- هذه النسخة لا تتحايل على الحماية أو تسجيل الدخول في موقع الوزارة.
